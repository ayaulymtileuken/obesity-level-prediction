# Obesity Level Classification using Machine Learning

## Overview

This project predicts obesity levels using lifestyle, dietary habits, and physical condition data from the UCI Machine Learning Repository.
The goal is to identify the most influential factors associated with obesity and compare the performance of several machine learning models for multi-class classification.

## Dataset

Source:
UCI Machine Learning Repository
- 2,111 observations
- 17 input features
- 7 obesity classes
Features include:
- Age
- Gender
- Height
- Weight
- Family history
- Physical activity
- Water consumption
- Eating habits
- Transportation type
- Alcohol consumption
- Technology usage
---
## Project Workflow
- Data cleaning
- Duplicate removal
- Exploratory Data Analysis (EDA)
- Feature encoding

- Model training
- Hyperparameter tuning
- Model comparison
- Performance evaluation
---
## Models

- K-Nearest Neighbors
- Decision Tree
- Random Forest
- XGBoost
---
## Evaluation
Models were evaluated using:
- Accuracy
- Weighted Precision
- Weighted Recall
- Weighted F1-score
- Confusion Matrix
---
## Key Findings
- Weight and family history were among the strongest predictors.
- Tree-based ensemble models outperformed simpler classifiers.
- Random Forest and XGBoost achieved the best overall performance.
